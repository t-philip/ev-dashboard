EV Dashboard

A personal, self-hosted, read-only dashboard for your own electric vehicle's data.

Status: in development. There is no release yet.

What it will show

  • Battery level and range over time
  • Charging sessions
  • Trips and efficiency
  • Current status: locks, doors, windows, tyres, service
  • Location, only if you turn it on

Principles

  • You run it yourself, and your data is designed to stay on your own machine.
  • Designed to be read-only: it does not control the vehicle.
  • Every user registers their own developer application with the manufacturer.
